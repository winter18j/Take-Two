# Hez2 Adaptive Audio Mastered Pack

This is the mastered version of the original Hez2 adaptive placeholder audio pack.

What changed:
- Louder and more consistent levels
- Gentle compression/limiting
- Cleaner low-end
- Slight air/presence boost
- Subtle short room ambience
- Mobile-game-safe peaks

Use these files in the app instead of the non-mastered placeholders.

Recommended:
- Music volume: 0.65 to 0.75
- Button SFX volume: 0.55 to 0.75
- Player presentation transition SFX: 0.75 to 0.9
- Crossfade music tracks over 1.25 to 1.5 seconds
